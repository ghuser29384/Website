Developers

Use the static data carefully.

PainMap data is public and read-only, but it is not a universal moral scoreboard. Keep provenance, uncertainty, and method fields attached to every value you reuse.

Quickstart

Fetch the contract

curl https://painmap.org/v1/releases.json
curl https://painmap.org/releases/2026-05-31/manifest.json
curl https://painmap.org/data/openapi.json
curl https://painmap.org/data/place-measurements.json
curl https://painmap.org/v1/places/BRA.json
curl https://painmap.org/data/provenance-registry.json

The API has no authentication and no write side. Use immutable release URLs for reproducible work; use latest aliases only when freshness matters more than exact replay.

must keep

Provenance

Carry source ids, source vintage, evidence kind, confidence bounds, uncertainty class, release id, and license id with every copied value.

must not

Overclaim

Country and ADM1 rows are directional proxies unless the evidence kind says direct or modeled.

security

Headers

The repository includes a static-host header policy and a Vercel header config for CSP, referrer policy, nosniff, and permissions policy.
