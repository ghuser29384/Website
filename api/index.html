API

Read-only public contract

PainMap's current public API is a set of static files. They are cacheable, inspectable, and safe for static hosting. Immutable release URLs are the reproducible contract; the latest alias is only a convenience pointer.

GET only

Read-only

No forms, accounts, submissions, or write endpoints are exposed on the public static site.

cacheable

Static hosting

The contract is designed to work on GitHub Pages, Vercel, Cloudflare Pages, or any static file host.

auditable

Source fields

Visible atlas rows must carry source ids, source vintage, evidence kind, confidence bounds, uncertainty, and license pointers.
