Policy

Editorial policy

PainMap should make the evidence boundary visible wherever a claim appears, especially when a value is modeled, inferred, or used only as a proxy.

  • Method notes should identify the source, model assumption, last meaningful update, and estimate kind.
  • Country proxy context should never be presented as a direct event pain estimate.
  • Major source or model changes should be reflected in the changelog.
  • Corrections should prioritize source accuracy, accessibility, uncertainty, and citation clarity.
