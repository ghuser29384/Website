Policy

Accessibility statement

PainMap treats accessibility as part of the product: visualizations need table equivalents, maps need search paths, and dynamic updates need programmatic status messages.

  • The place search is intended as the keyboard and screen-reader equivalent to the map.
  • Charts and rankings include table equivalents for inspection and reuse.
  • Loading, selection, and search-result updates use live status regions where practical.
  • The site respects reduced-motion preferences for non-essential transitions.
  • The static site check validates route metadata, links, reduced-motion CSS, and release surfaces; rendered homepage and key routes are screenshot-tested before release.
  • The current WCAG 2.2 AA audit matrix is published at /policies/accessibility/audit-2026-06-05/ with machine-readable status at /data/accessibility-audit.json.
