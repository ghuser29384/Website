Privacy policy

PainMap is a public, static research visualization. It does not ask for names, emails, health symptoms, accounts, uploads, payment information, or clinician/patient records.

  • No personal-data workflow is part of this public site.
  • No symptom entry, patient account, saved view, form submission, or payment flow is provided.
  • Privacy-preserving telemetry is limited to the public event vocabulary at /data/analytics-events.json.
  • Third-party fetch behavior is published at /data/third-party-fetches.json, with snapshot mode documented as release-materialized and live overlays documented as opt-in public-source requests.
  • Allowed events include route_view, atlas_place_selected, dataset_download, compare_opened, release_manifest_opened, place_search_started, zero_result_search, data_fetch_timing, and web_vital.
  • Telemetry does not include user ids, precise user location, query strings, personal-health fields, or cross-site tracking. The static site has no default network collector.
  • Any future personal-data product should use a separate compliant service boundary and its own policy.
