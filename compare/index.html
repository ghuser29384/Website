Glossary

Compare terms

Canonical country profile
Release rows that were explicitly built and scored for country-level comparison.
Boundary-only coverage
Map-visible places that still need canonical release rows before rankings can be treated as direct comparison values.
ADM1 context
Subnational context rows used for coverage and distributional context, not yet canonical country comparisons.
No release coverage
No release rows are present for the requested place in this snapshot.
Proxy aggregate
Modeled aggregate estimate from public indicators; useful for comparison with clear uncertainty signals.
Priority overlay
Priority-visible layer used for allocation/attention framing, not a direct suffering estimate.
Direct evidence
Observed release-linked source output for the place and layer, rather than a proxy pathway.
Ranking mode
How values are transformed into ranks (for example, higher proxy score = higher attention).
Not directly comparable
Rows only remain comparable when layer, value model, unit, ranking mode, reference period, source vintage, and method version align.
Value model
How a value row is numerically defined before ranking, such as proxy burden, life-years, or direct count.
Reference period
The time window used for the value in this release row.
Source vintage
Source dataset revision or timestamp that was used to produce this release row.
Uncertainty
How much confidence and interval width applies to the value; lower precision should not be treated as fixed evidence.
Method version
Registered transformation logic that maps source values into this ranking-compatible release value.
