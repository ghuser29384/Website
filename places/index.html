Key terms

Coverage and comparability glossary

Canonical country profile
Countries with release-scoped measurement rows and rows eligible for direct side-by-side comparison.
Boundary-only coverage
Countries shown in the map boundary set without canonical pain values in this release.
ADM1 context
Subnational context rows shown for distributional hints, not canonical comparison rows unless explicitly promoted.
No release coverage
Place not currently represented in the active release in a comparable row format.
Proxy aggregate
Indicator-derived estimates used where direct evidence rows are not published in the release.
Priority overlay
Attention-first ranked layer used to guide review and action pathways, distinct from direct comparison rows.
Modeled estimate
Computed outputs that rely on transform logic, assumptions, or proxy substitution to estimate place-level burden.
Direct place evidence
Canonical measurements published directly for a place in this release and suitable for direct comparison.
Ranking mode
The ordering contract for a row family, including whether lower is worse, higher is worse, or whether uncertainty changes sort behavior.
Not directly comparable
Rows only compare directly when coverage mode, unit, value model, ranking mode, source vintage, reference period, and method version align.
Coverage status
Release-derived state that determines whether a place has canonical rows, context-only rows, or no release rows.
Value model
How a value was represented numerically before ranking (for example, proxy burden, direct estimate, or transformed life-years).
Reference period
The date window represented by the value row, kept so incomparable time windows are not mixed.
Source vintage
The upstream source revision or snapshot date used to generate the release row.
Uncertainty
How much confidence and interval width applies to this value; lower precision should not be treated as fixed evidence.
Method version
The registered transformation method used to convert source data into this release row.
