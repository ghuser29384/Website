Dataset

Place measurements

Canonical static release artifact for the atlas contract. Each row carries typed numeric values, display values, units, evidence kind, ranking mode, geography hierarchy, source ids, confidence bounds, release id, and license pointer.

Schema

Core fields

Field-level contract for the place measurements export.
Field Meaning Required
place_idISO3, WLD, or future ADM1 identifier.Yes
layer_idStable layer key such as factory-farmed-animals or human-burden.Yes
release_idImmutable release identifier, currently 2026-05-31.atlas.2.Yes
evidence_kindDirect, modeled, proxy, priority-overlay, or boundary.Yes
raw_valueNumeric value used for ranking or comparison.Yes
display_valueHuman-readable value shown in cards and tables.Yes
unit_labelUnit attached to the numeric field.Yes
ranking_modeHow higher or lower values should be interpreted.Yes
source_idsArray of source pointers into the provenance registry.Yes
confidence_low / confidence_highRelease-scoped numeric bounds for the value.Yes
source_vintageDataset date window or review date for the visible value.Yes
extraction_timestampRelease-scoped timestamp for the source extraction or review cut used to materialize the row.Yes
transform_versionStatic transform version that generated the measurement lineage and downstream artifacts.Yes
reviewer_statusRelease review state for the measurement row, currently release-reviewed.Yes
source_file_checksumSHA-256 checksum over the canonical measurement source row and referenced provenance source rows.Yes
uncertainty_classModerate, low, or very-low confidence class.Yes
license_idPointer into the provenance registry license table.Yes
