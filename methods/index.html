Methods

How to read PainMap

PainMap separates direct evidence, modeled estimates, proxy aggregates, and priority overlays. The event layer uses Welfare Footprint pain-intensity definitions and public estimates; the atlas layer uses directional burden proxies and explicitly labeled decision-support overlays.

Direct

Direct welfare estimate

A claim drawn from a welfare research estimate for a defined event, species, system, and time window.

Modeled

Model-based estimate

A public estimate that combines empirical inputs with assumptions about duration, intensity, or production context.

Proxy

Country proxy aggregate

A directional scale indicator built from public datasets. It should not be read as a direct pain measurement.

Priority overlay

Decision-support overlay

A layer that combines proxies, evidence salience, and tractability notes. It is useful for triage, not for claiming measured pain totals.

  • Welfare Footprint intensity language is used as an anchor, not a perfect human-animal conversion.
  • Place context keeps source, vintage, evidence kind, confidence interval, and uncertainty visible beside ranked values.
  • Major assumptions, source type, confidence, and last review date should be visible beside the estimate.
